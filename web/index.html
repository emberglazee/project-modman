⚙️ Project Modman : merge conflicting mods

Merges Project Wingman mods that edit the same files, with no metadata and no PSM needed. Everything runs locally in your browser. Nothing is uploaded; after loading, this page makes zero network requests.

First time here? Start with this

  1. Extract the mod archives first. A .zip or .7z renamed to .pak is not a pak.
  2. Add the *_P.pak files from those folders below.
  3. Point at pakchunk0-WindowsNoEditor.pak in your own install.
  4. Press Merge, then drop the downloaded file into your ~mods folder and remove the paks you merged.
