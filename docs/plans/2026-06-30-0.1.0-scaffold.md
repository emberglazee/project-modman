# Project Modman 0.1.0 — Scaffold Implementation Plan

> **For Hermes:** Implement this plan task-by-task. Each task is 2-5 minutes of focused work with verification.

**Goal:** Create the workspace skeleton with 4 empty crate directories, a basic CLI that responds to `--version` and `--help`, and CI/CD workflows that build across 3 platforms.

**Architecture:** Cargo workspace with separate crates for core, uasset, pak, and cli. CI reuses HoM's proven reusable-workflow pattern with matrix builds.

`crates/modman-cli/src/main.rs`:
```rust
use clap::{Parser, Subcommand};

#[derive(Parser)]
#[command(name = "modman", version, about = "Project Modman — Project Wingman Modding Utility")]
struct Cli {
    #[command(subcommand)]
    command: Option<Commands>,
}

#[derive(Subcommand)]
enum Commands {
    /// Print .pak file info
    Info {
        /// Path to the .pak file
        input: String,
    },
    /// List files in a .pak
    List {
        /// Path to the .pak file
        input: String,
    },
    /// Unpack a .pak file to a directory
    Unpack {
        /// Path to the .pak file
        input: String,
        /// Output directory
        #[arg(short, long)]
        output: Option<String>,
    },
    /// Pack a directory into a .pak file
    Pack {
        /// Input directory
        input: String,
    },
    /// Build a merged mod from Sicario patch files (drop-in replacement for Sicario CLI)
    Build {
        /// Paths to preset/mod files or directories
        preset_paths: Vec<String>,
        /// Path to the game install directory (auto-detected if omitted)
        #[arg(long)]
        install_path: Option<String>,
    },
}

fn main() {
    let cli = Cli::parse();

    match cli.command {
        Some(Commands::Info { input: _ }) => {
            eprintln!("info: not yet implemented — coming in 0.2.0");
        }
        Some(Commands::List { input: _ }) => {
            eprintln!("list: not yet implemented — coming in 0.2.0");
        }
        Some(Commands::Unpack { input: _, output: _ }) => {
            eprintln!("unpack: not yet implemented — coming in 0.3.0");
        }
        Some(Commands::Pack { input: _ }) => {
            eprintln!("pack: not yet implemented — coming in 0.4.0");
        }
        Some(Commands::Build {
            preset_paths: _,
            install_path: _,
        }) => {
            eprintln!("build: not yet implemented — coming in 0.11.0");
        }
        None => {
            println!("Project Modman v{} — a Project Wingman modding utility", env!("CARGO_PKG_VERSION"));
        }
    }
}
```

### Task 6: Create reusable CI workflow for Rust builds

**Objective:** Create the `rust-build.yml` reusable workflow that checks, builds, and tests across 3 platforms. Modeled after HoM's `server-build.yml`.

**Files:**
- Create: `.github/workflows/rust-build.yml`

**Implementation:**

`.github/workflows/rust-build.yml`:
```yaml
name: Rust Build (Reusable)

on:
  workflow_call:

jobs:
  check:
    name: Check
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v6

      - name: Install Rust
        uses: dtolnay/rust-toolchain@stable
        with:
          components: clippy, rustfmt

      - name: Rust Cache
        uses: Swatinem/rust-cache@v2

      - name: Formatting Check
        run: cargo fmt --check

      - name: Clippy
        run: cargo clippy -- --deny warnings

      - name: Test
        run: cargo test
        env:
          RUST_BACKTRACE: 1

  build:
    name: Build (${{ matrix.os }} - ${{ matrix.target }})
    needs: check
    runs-on: ${{ matrix.os }}
    strategy:
      matrix:
        include:
          - os: ubuntu-latest
            target: x86_64-unknown-linux-gnu
            suffix: linux
          - os: windows-latest
            target: x86_64-pc-windows-msvc
            suffix: win.exe
          - os: macos-latest
            target: aarch64-apple-darwin
            suffix: macos-arm64
    steps:
      - uses: actions/checkout@v6

      - name: Install Rust
        uses: dtolnay/rust-toolchain@stable
        with:
          targets: ${{ matrix.target }}

      - name: Rust Cache
        uses: Swatinem/rust-cache@v2

      - name: Build
        run: cargo build --release --target ${{ matrix.target }}

      - name: Upload Binary
        uses: actions/upload-artifact@v7
        with:
          name: modman-${{ matrix.suffix }}
          path: |
            target/${{ matrix.target }}/release/modman
            target/${{ matrix.target }}/release/modman.exe
          if-no-files-found: ignore

  test-cross:
    name: Test (${{ matrix.os }})
    needs: check
    runs-on: ${{ matrix.os }}
    strategy:
      matrix:
        os:
          - windows-latest
          - macos-latest
    steps:
      - uses: actions/checkout@v6

      - name: Install Rust
        uses: dtolnay/rust-toolchain@stable

      - name: Rust Cache
        uses: Swatinem/rust-cache@v2

      - name: Run Tests
        run: cargo test
        env:
          RUST_BACKTRACE: 1
```

### Task 8: Create release workflow

**Objective:** Create the `release.yml` that builds all platforms and creates a GitHub release on workflow_dispatch with version bump.

**Files:**
- Create: `.github/workflows/release.yml`

**Implementation:**

`.github/workflows/release.yml`:
```yaml
name: Release

on:
  workflow_dispatch:
    inputs:
      bump:
        description: 'Version bump type'
        required: true
        default: 'patch'
        type: choice
        options:
          - patch
          - minor
          - major
          - none

concurrency:
  group: ${{ github.workflow }}-${{ github.ref }}
  cancel-in-progress: true

jobs:
  build:
    uses: ./.github/workflows/rust-build.yml

  create-release:
    name: Create Release
    needs: build
    runs-on: ubuntu-latest
    permissions:
      contents: write
    steps:
      - uses: actions/checkout@v6

      - name: Bump Version
        id: bump
        run: |
          if [ "${{ inputs.bump }}" != "none" ]; then
            # Read current version from workspace Cargo.toml
            CURRENT_VERSION=$(grep '^version = ' Cargo.toml | head -1 | sed 's/.*"\(.*\)"/\1/')
            IFS='.' read -r MAJOR MINOR PATCH <<< "$CURRENT_VERSION"
            
            case "${{ inputs.bump }}" in
              major) MAJOR=$((MAJOR + 1)); MINOR=0; PATCH=0 ;;
              minor) MINOR=$((MINOR + 1)); PATCH=0 ;;
              patch) PATCH=$((PATCH + 1)) ;;
            esac
            
            NEW_VERSION="${MAJOR}.${MINOR}.${PATCH}"
            
            # Update version in workspace Cargo.toml
            sed -i "s/^version = \".*\"/version = \"$NEW_VERSION\"/" Cargo.toml
            
            cargo generate-lockfile
            
            git config user.name "github-actions[bot]"
            git config user.email "github-actions[bot]@users.noreply.github.com"
            git add Cargo.toml Cargo.lock
            git commit -m "chore: bump version to $NEW_VERSION"
            git push
          fi
          
          FINAL_VERSION=$(grep '^version = ' Cargo.toml | head -1 | sed 's/.*"\(.*\)"/\1/')
          echo "VERSION=$FINAL_VERSION" >> $GITHUB_OUTPUT

      - name: Download Linux Binary
        uses: actions/download-artifact@v8
        with:
          name: modman-linux
          path: release-bin/

      - name: Download Windows Binary
        uses: actions/download-artifact@v8
        with:
          name: modman-win.exe
          path: release-bin/

      - name: Download macOS ARM64 Binary
        uses: actions/download-artifact@v8
        with:
          name: modman-macos-arm64
          path: release-bin/

      - name: Prepare Release Assets
        run: |
          chmod +x release-bin/modman 2>/dev/null || true
          chmod +x release-bin/modman-macos-arm64 2>/dev/null || true
          # Rename for clarity
          mv release-bin/modman release-bin/modman-linux 2>/dev/null || true
          mv release-bin/modman.exe release-bin/modman-win.exe 2>/dev/null || true

      - name: Create GitHub Release
        uses: softprops/action-gh-release@v3
        with:
          tag_name: v${{ steps.bump.outputs.VERSION }}
          name: v${{ steps.bump.outputs.VERSION }}
          files: release-bin/*
          draft: false
          prerelease: ${{ contains(steps.bump.outputs.VERSION, '-') }}
        env:
          GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}
```

File exists: `.github/workflows/release.yml`

**Commit:**
