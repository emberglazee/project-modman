# Project Modman 0.8.0 — Fragment DSL Parser

**Goal:** Implement the template parser that translates Sicario fragment DSL strings into a chain of executable fragment operations.

---

### Task 1: Create fragment types and parser in modman-core

**Files:**
- Create: `crates/modman-core/src/fragment/mod.rs`

The fragment DSL grammar:
```
template = type_loader ":" fragment_chain
type_loader = identifier ("(" parameter? ")")?
fragment_chain = fragment ("." fragment)*
```

Fragment syntaxes:
| Syntax | Type |
|--------|------|
| `['name']` or `[!name]` | StructFragment |
| `[N]` | ArrayFragment |
| `{name}` | StructPropertyFragment |
| `{Type:{Name=Value}}` | StructMatchFragment |
| `[[N]]` | ArrayPropertyFragment |
| `[[*]]` | ArrayFlattenFragment |
| `<type>` | PropertyValueFragment (by type) |
| `<type=value>` | PropertyValueFragment (by type+value) |
| `<type::value>` | EnumValueFragment |
| `[*]` | AnyFragment |
| `{**}` | FlattenFragment |
